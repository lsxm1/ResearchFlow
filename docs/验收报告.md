# ResearchFlow 验证报告

应用基线为 `75fa172`。本地验证使用交付样本和论文原文，并通过 26 项后端回归及前端生产构建。

| 场景 | 验证结果 |
|---|---|
| 文献版本管理 | 改名后的 Transformer v1/v7 正文相似度约 0.75，可保留、归档和恢复，历史引用可访问 |
| 英文 OCR 和长文解析 | 15 页扫描件可检索，第 7 页命中 P100 证据。541 页教材提取 537 个文本页，可访问末页 |
| 跨论文对比 | Transformer/BERT 架构及训练字段可定位到各自原文。Pythia-410M 的 32 块 GPU 定位到第 4 页表 3 的数量单元格 |
| 证据冲突与导出 | ALBERT-xxlarge 第 5 页正文 233M 和表格 235M 分别保留出处。报告记录页码及表格行列 |
| 检索与写作 | arXiv 检索、主题刷新与反馈、BERT 指向 Transformer 的引用边、带引用提纲及三种图表脚本通过验证 |
| 本地模型 | 本地 Qwen 生成对比检索词，完成短句和 Transformer 第 7 页翻译。普通问答核对了第 7 页的 8 块 P100 GPU |

## 三篇 GPT 论文联合对比

使用 GPT-1、GPT-2 和 GPT-3 原始论文。GPT-1 第 5 页记录训练序列 512 tokens，GPT-2 第 4 页记录 1,024 tokens 的上下文窗口，并可定位表 2 的 1542M 参数单元格。GPT-3 报告 175B 参数与 2,048 tokens。证据缺口和不同统计口径在对比结果中明确标出。
