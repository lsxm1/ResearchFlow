# ResearchFlow 六模块演示路线

启动使用 `powershell -NoProfile -ExecutionPolicy Bypass -File .\start.ps1 -LocalModel`，浏览器访问 `http://127.0.0.1:8000`。演示库初始只放 Transformer v7。扫描件、旧版、长教材可以预先准备在本地文件夹，BERT 由任务当场导入。

| 时段 | 操作与验收 |
|---|---|
| 0:00–0:45 | 介绍科研助手及证据工作台。展示 PDF 导入、解析进度，补充改名后的 v1、图像扫描件与长教材的验证结果。 |
| 0:45–2:20 | 只勾选 Transformer，运行「BERT 继承了 Transformer Encoder 的什么，又改了什么？」展示模型检索词、自动补齐 BERT、任务拆解，以及附双方原文的两条结论。 |
| 2:20–3:20 | 从结论直接定位 BERT 第 13 页的训练损失。展示原页证据高亮、目录、数字引用往返和本地译文。展示预先翻译好的页面时说明译文来自同一服务。 |
| 3:20–4:15 | 在 arXiv 检索与追踪页建一个主题，刷新后展示真实结果、推荐理由和赞踩反馈。 |
| 4:15–5:10 | 在两篇文献范围内生成局域引用图谱，点击 BERT 到 Transformer 的引用边核对参考文献。展示库内 PageRank 和未来工作线索。 |
| 5:10–6:30 | 下载研究报告，展示证据、引用关系和论文提纲。上传 `samples/chart-demo.csv`，预览图、检查图注并导出脚本。该 CSV 是演示样例。 |

网络或模型异常时，展示页面上的真实状态。已入库论文可复用。模型没有找到可核对的摘录时，表格仍保留原文候选和补查记录。

需要展示证据缺口时，用同一入口问「比较两篇论文的训练硬件和训练能耗」，在目标栏填 BERT 的 arXiv 编号 1810.04805。训练能耗经过补查仍未命中时，界面会保留缺口。
