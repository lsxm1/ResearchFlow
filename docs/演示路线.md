# ResearchFlow 六模块演示路线

启动使用 `powershell -NoProfile -ExecutionPolicy Bypass -File .\start.ps1 -LocalModel`，浏览器访问 `http://127.0.0.1:8000`。提前导入 Pythia 和 ALBERT，并保存已完成的对比任务。录制时先只选 Transformer，由任务补齐 BERT。网络不稳定时，可提前导入包内 BERT，展示库内复用流程。

| 时段 | 操作与验收 |
|---|---|
| 0:00–1:10 | 介绍科研助手，展示 PDF 导入和解析进度。只选 Transformer，点「Adam β 参数」，核对第 7 页的 β₁ = 0.9、β₂ = 0.98，再点「返回任务」。 |
| 1:10–2:20 | 只勾选 Transformer，运行「BERT 继承了 Transformer Encoder 的什么，又改了什么？」展示模型检索词、自动补齐 BERT、任务拆解，以及附双方原文的两条结论。 |
| 2:20–3:45 | 查看训练实验示例，比较 Transformer Big 和 BERT Large 的设备及耗时，指出 BERT 的步数缺少型号归属。切到 Pythia 对比任务，点开第 4 页的 32 块 GPU 单元格，指出旁边 GPT-3 对照列的 8 块，再点「返回对比」。 |
| 3:45–4:45 | 点开 BERT 原页，展示原文高亮和本地译文。切到检索与追踪页展示 arXiv 推荐结果、推荐理由和反馈。 |
| 4:45–5:35 | 生成局域引用图谱，展示 BERT 对 Transformer 的引用边及其来源。 |
| 5:35–6:40 | 下载研究报告，展示证据、引用关系和论文提纲。上传 `samples/chart-demo.csv`，预览图表、核对图注并导出绘图脚本。 |

网络或模型异常时，展示页面上的真实状态。已入库论文可复用。模型没有找到可核对的摘录时，表格仍保留原文候选和补查记录。

要演示按型号取值，可勾选 BERT 和 ALBERT，问「比较两篇论文 Base 版的参数量」。要复现 ALBERT 的两处冲突证据，可勾选 ALBERT、GPT-2 和 GPT-3，问「比较三篇论文自己报告的最大模型参数量」。

录制前可勾选 Pythia 和 BERT 预跑「比较 Pythia-410M 和 BERT Large 的训练设备」。解释 Agent 如何按型号补查、如何在表格里按列名取值，以及为什么训练条件不同会限制效率比较。正式视频用普通话讲解，导出 1080p 或更高分辨率的 MP4。

需要展示证据缺口时，用同一入口问「比较两篇论文的训练硬件和训练能耗」，在目标栏填 BERT 的 arXiv 编号 1810.04805。训练能耗经过补查仍未命中时，界面会保留缺口。
