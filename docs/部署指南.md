# ResearchFlow 部署指南

## 在线演示

打开 [ResearchFlow](https://researchflow-production-c46afc77.up.railway.app/)，使用评审账号 `reviewer` 登录。线上采用证据模式，支持 PDF 上传、对比、原文高亮及报告导出。演示实例使用临时存储。

## Windows 本地使用

启动方式见 [README](../README.md)。使用 `-LocalModel` 启动时，脚本会配置本地 Qwen 推理服务。

## Docker 自托管

1. 从 [源码仓库](https://github.com/lsxm1/ResearchFlow) 检出项目，或从交付包内的 Git bundle 恢复源码。
2. 在项目根目录复制 `.env.example` 为 `.env`。需要模型时配置容器可访问的兼容接口。对外开放时设置 `RF_DEMO_PASSWORD`，用户使用 `reviewer` 与配置的口令登录。
3. 执行 `docker compose up -d --build`。Compose 将服务映射至本机 `127.0.0.1:8000`，使用命名数据卷保存 PDF 及 SQLite。对外访问可用 HTTPS 反向代理转发此端口。
